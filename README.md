## Structure

```
chandramouli-curriculum/
├── README.md
├── templates/
│   ├── pre-read-template.md
│   └── lecture-script-template.md
└── <batch-id>/                      ← one folder per batch (ID from the INI sheet)
    └── module-01-<topic>/
        └── lecture-01-<topic>/
            ├── pre-read.md
            └── lecture-script.md
```

## Naming rules

- Lowercase and hyphens only.
- Number modules and lectures with two digits: `module-01-<topic>`, `lecture-01-<topic>`.
- Every lecture folder holds exactly two files: `pre-read.md` and `lecture-script.md`.
- Everyone, including aligning SMEs, starts from the files in `templates/`.
